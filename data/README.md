# Data Readme

## Introduction

The publication data CSV files were generated on 2025-01-22 by Josh Lawrimore using the NIH RePORTER Web Application. The files are publications funded by the NIMH between 2020 and 2025. The timestamp of the download is in the file name.

The files have the following columns:

- Core Project Number
- Affiliation
- Pub Year
- Authors
- Country
- ISSN
- Journal Issue
- Journal (Link to PubMed abstract)
- Journal Title ABBR
- Journal Volume
- Language
- Page Number
- PMC ID
- PMID
- PUB Date
- Title (Link to full-text in PubMed Central)
- Related Publications in PubMed
- Related Publications in Google Scholar
- Articles Citing from PubMed Central
- Articles Citing from Google Scholar
- Relative Citation Ratio
